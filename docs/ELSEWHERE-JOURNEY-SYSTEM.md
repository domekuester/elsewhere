# ELSEWHERE Journey system

A journey is a period of travel, not a country. Malaysia and Thailand therefore each reference several journey records while retaining one destination identity.

Implemented fields include stable ID/slug, nullable public title, working title, owner date range and confidence, destination IDs, hero/photo/story/people/fragment relationships, editorial summary, owner notes, publication status and manual photo order.

All ten timeline journeys exist as `needs-owner-input`. None receives a public page until it has a strong opening frame, a reviewed sequence, an owner-approved introduction and a meaningful continuation. Chronology remains available; manual photographic order controls published pages.

The local Studio can filter by journey and review every date-range assignment. Batch destination assignment infers a journey only when the selected capture date lies inside that destination’s clear owner range.
