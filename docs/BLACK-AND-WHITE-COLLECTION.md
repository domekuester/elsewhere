# Black & White Collection

## Editorial premise

Black & White is a quiet room inside ELSEWHERE. It brings together gesture, labour, weather, reflection, and distance. It is not a desaturation control and does not contain converted colour photographs.

## Presentation rules

Use true black, neutral white, longer pauses, fewer captions, and alternating image scale. Do not add fake film borders, grain, contact-sheet decoration, or grayscale UI effects. Colour returns only through the ultramarine memory mark and the path back into another world.

## Routes

- `/collections/` introduces authored edits.
- `/collections/black-and-white/` contains the current monochrome sequence.
- Homepage threshold: `#black-and-white`.

Future additions should be admitted through an edit, not by matching a pixel-saturation threshold alone.
