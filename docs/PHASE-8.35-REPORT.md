## Black & White

## Archive

The number beneath each photograph now represents the stable public archive index. It is neutral, compact, aligned with the year, hidden from assistive technology as redundant decoration, and turns ultramarine only during interaction. Gallery row breathing, mobile frame variation, hover behavior, and metadata hierarchy were refined without converting the archive into masonry or a grid dashboard.
