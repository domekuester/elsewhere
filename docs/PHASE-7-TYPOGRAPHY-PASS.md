# Phase 7 — typography pass

The type system keeps its dependency-free architecture while improving the available platform stacks:

- Display: Avenir Next Condensed first, followed by condensed Helvetica/Arial fallbacks.
- Editorial: Baskerville first, followed by Iowan Old Style, Palatino, and Georgia.
- Interface: Avenir Next / Helvetica Neue.

The hero now creates tension between a poised condensed first line and a restrained italic editorial second line. The wordmark uses a small italic editorial gesture with tighter tracking. Archive gains an italic editorial title; navigation becomes slightly smaller and more deliberate.

Extreme negative tracking was capped at `-0.04em`. Captions remain quiet but readable. Font synthesis is disabled, antialiasing is enabled, and the system does not introduce render-blocking remote fonts. The result is more sensual through contrast and rhythm—not indiscriminate scale.
