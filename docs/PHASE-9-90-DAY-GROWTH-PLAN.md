# Phase 9 — 90-day growth plan

Built for one person doing this alongside other work. No daily content schedule, no posting quota.
Roughly **3–5 hours a week**, concentrated where it produces something.

The plan assumes the honest truth: a new site has no traffic, and traffic is not the fastest route
to revenue anyway. Studio and Licensing do not need an audience — they need the right five people to
see the work.

---

## Month 1 — Launch and be findable

**Goal: the site is live at a real address, Google knows it exists, and the first outreach has gone out.**

### Week 1 — Launch mechanics (~3 hours)
- Choose and register a domain
- Connect it to Vercel, set `SITE_URL`, `PUBLIC_CONTACT_EMAIL`, `PUBLIC_CREATOR_NAME`, redeploy
- Verify social previews by pasting the URL into a message
- Book the *Steuerberater* / lawyer conversation for the Impressum and privacy policy

### Week 2 — Legal and search (~3 hours)
- Publish the Impressum and privacy policy once the details are confirmed
- Verify Search Console, submit both sitemaps
- Request indexing for the eight key pages
- Decide on analytics (or deliberately ship none)

### Week 3 — First outreach (~4 hours)
- Build a list of **ten** places: boutique hotels, restaurants, cafés you have actually been to or
  genuinely admire, whose photography is visibly weak
- Send **five** personal messages. Not a template blast — see the outreach system doc
- Track them in a plain list: who, when, response

### Week 4 — Second wave and review (~3 hours)
- Five more messages
- Follow up once on week 3's silence, then stop
- Check Search Console for first impressions

**End of month 1:** live, indexed, ten real approaches made. Possibly a first conversation.

---

## Month 2 — Depth

**Goal: more of the archive becomes publishable, and the first genuine writing exists.**

### Weeks 5–6 — One destination (~5 hours total)
Pick the strongest unpublished destination — La Réunion has 114 photographs and the two best
landscapes in the archive. Classify, sequence, and bring it to publication threshold. A second
destination chapter roughly doubles the site's indexable editorial surface.

### Week 7 — First Field Note (~4 hours)
One note. About a place you actually went. Written from memory and photographs, not research.

The test: could someone who has never been there picture it, and would they know something useful
afterwards? If it reads like it could have been assembled from other websites, do not publish it.

### Week 8 — Print shortlist and outreach (~3 hours)
- Review the print shortlist, pick your twelve
- Order three test prints
- Five more outreach messages

**End of month 2:** two destination chapters, one real Field Note, prints physically in your hands,
fifteen approaches made.

---

## Month 3 — Test what actually works

**Goal: find out which paths produce real conversations, and stop guessing.**

### Weeks 9–10 — Second Field Note and rights review (~5 hours)
- Second Field Note, same standard
- Review rights on any photograph someone has enquired about — no more than that

### Week 11 — Measure (~2 hours)
Look at what happened, not what you hoped:
- Where did visitors come from?
- Which destination held attention?
- Did anyone reach Studio? Did anyone enquire?
- Which search queries appeared in Search Console?

### Week 12 — Adjust (~3 hours)
Do more of whatever produced a real conversation. If outreach worked, do more outreach. If a Field
Note brought search traffic, write another like it. If licensing enquiries arrived, put the effort
into rights review.

**End of month 3:** you know which channel is real for you, and you have stopped spreading effort
evenly across channels that are not.

## What to measure monthly

Five minutes, once a month, in a plain note:

| | Month 1 | Month 2 | Month 3 |
| --- | --- | --- | --- |
| Visitors | | | |
| Google impressions | | | |
| Google clicks | | | |
| Image search clicks | | | |
| Studio enquiries | | | |
| Licensing enquiries | | | |
| Print interest | | | |
| Field Notes published | | | |
| Outreach sent / replied | | | |

**Enquiries matter more than visitors.** One serious hotel conversation outweighs a thousand
sessions. Do not build a dashboard for this — a note is enough.

---

## What not to do

- **Do not post daily anywhere.** It will not produce a commission and it will exhaust you.
- **Do not publish thin Field Notes to have more pages.** Thin content suppresses good content.
- **Do not add advertising.** At this traffic it earns nothing and costs the reading experience.
- **Do not chase a hundred cold emails.** Ten researched approaches beat a hundred scraped ones.
- **Do not rebuild the site.** It is finished. Use it.

---

## Realistic expectations

**Likely by day 90:** a live indexed site, two or three destination chapters, one or two Field Notes,
a handful of real conversations, and — with reasonable luck — one paid Studio project or licence.

**Unlikely by day 90:** meaningful search traffic, print sales, affiliate income.

That is not pessimism. Search takes six to twelve months to compound; prints need demand before
supply; affiliate needs traffic first. The channels that can pay early are the ones that depend on
your work being seen by the right person rather than by many people — which is exactly what the
Studio and Licensing layers are for.
