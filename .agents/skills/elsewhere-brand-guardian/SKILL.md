# ELSEWHERE Brand Guardian

Ask two questions before approving a direction:

1. Could this belong to 500 other portfolio websites?
2. Does this feel like UI showing photography, or a photographic publication using a browser as its medium?

Reject or refine the first. Reject generic grids, rounded SaaS cards, glassmorphism, gradient blobs, fake editorial language, awards, quotes, logos, film grain, contact sheets, analog borders, camera UI, film-strip clichés, novelty masonry, cursor tricks, scroll hijacking, forced smooth scrolling, indiscriminate parallax, constant fades, and gratuitous transitions.

Shared language must not create cloned pages. Allow Destination, Journey, Archive, People, B&W, and Home to have distinct tempos while preserving authored type, spacing logic, color, navigation, and photographic treatment.
