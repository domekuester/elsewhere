# Editorial Typography

Protect the authored relationship between Barlow Condensed and Literata. Do not replace either casually.

Inspect rendered type at representative desktop and mobile widths. Review display scale, hierarchy, measure, leading, tracking, caption density, navigation clarity, optical alignment, and widows/orphans where they affect composition. Judge how type supports or competes with photography.

Prefer adjustments to scale, measure, spacing, weight, and placement within the existing system. Report actual locations and visible consequences. Confirm text remains readable, reflows without collisions, and preserves semantic heading order and zoom resilience.
