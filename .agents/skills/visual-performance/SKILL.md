# Visual Performance

Luxury does not mean heavy.

Review LCP candidates, stable dimensions, responsive source selection, hero priority, lazy loading below fold, decode cost, font loading, CLS, DOM growth, animation cost, and mobile memory. Preserve incremental Archive rendering and minimal JavaScript. Load only genuine hero assets eagerly.

Require evidence before and after consequential changes: built asset sizes, request behavior, rendered dimensions, and relevant browser metrics. Do not trade crop integrity for arbitrary byte savings; choose the smallest delivery role that preserves the approved composition and display quality. No new runtime or dependency without a concrete need.
