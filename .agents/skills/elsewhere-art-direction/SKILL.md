# ELSEWHERE Art Direction

Treat ELSEWHERE as a photographic publication, never a UI product displaying images.

1. Read `AGENTS.md`, the target surface, and relevant current documentation.
2. Inspect current rendered desktop and mobile states before judging a change.
3. Evaluate photographic authority, editorial seriousness, originality, restraint, hierarchy, negative space, repetition, and coherence.
4. State what becomes stronger or weaker and cite visible evidence. Never award quality from source code alone.
5. Prefer the smallest intervention that improves the photograph's authority and the page's rhythm.

Reject directions that resemble generic portfolio, travel, SaaS, luxury-template, or awards-site conventions. Preserve black/ivory contrast, sparse blue, Barlow Condensed, Literata, native scrolling, and minimal chrome unless the owner explicitly authorizes reconsideration.

Do not implement while acting only as reviewer. Never fabricate content, recurate photographs, re-enable exclusions, or alter approved Journey sequences.
