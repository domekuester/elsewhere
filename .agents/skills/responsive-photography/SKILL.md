# Responsive Photography

Technical `object-fit` correctness is not a pass. Treat every rendered crop as a composition.

1. Inspect the actual image at 1440, 1280, 1024, 768, 430, and 390 where relevant.
2. Compare crop and scale against the uncropped approved asset without editing it.
3. Check faces, eyes, hands, bicycles, boats, horizons, gestures, and other focal subjects.
4. Flag aggressive mobile zoom, unsuitable landscape forcing, lost subject relationships, or full bleed that should be contained.
5. Recommend focal metadata or presentation changes for owner review; never invent a destructive crop.

Mobile is an authored editorial surface. Evaluate sequence, scale, text/image breathing room, and transitions—not only individual frames. Never modify source masters or regrade photographs.
